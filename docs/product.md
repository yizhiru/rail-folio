# 火车记产品规则

界面与统计口径。实现落在 `src/ui`、`src/stats`、`src/map`、`src/domain`。技术结构见 [architecture.md](architecture.md)。

## 文案

- 按钮与标题尽量短。解释性文字不常驻页面，放进顶栏右侧 **？**：悬停或聚焦时展示当前页说明。
- 空状态可以有一句操作提示（如「将图片拖到此处」），不要重复「？」里的长说明。
- 统计卡片上可以保留**数据性**附注（如「最常出现：杭州」），不要放口径说明（如「同城车站已合并」）。

各页「？」要点：

| 页 | 说明什么 |
|---|---|
| 总览 | 地图手势；城市按次数、同城合并、次数相同时近的在前；总时长与跨天；票价只计已填写的 |
| 行程 | 筛选与搜索；到达时刻 `+1` 表示次日 |
| 导入 | 选图 / 文件夹 / 拖入 / 12306；本机处理，不保存账号密码 |
| 录入 | 手录与智能导入；导出备份；数据只在本机 |

票面预览窗的操作说明同样进该窗的「？」，不在图下常驻。

## 总览地图

- **不画站名**。站多了会叠字；悬停圆点或线路时用 tooltip 显示名称。
- **车站圆点**要小、颜色淡，贴合深蓝底图，仍能和省界、线路分开。大小可随到访次数略变，但整体保持克制。
- **线路**按「起点 → 终点」聚合，**不分车型**；杭州→徐州与徐州→杭州仍是两条弧。次数为该方向全部车次之和。
  - 1 次：细、淡
  - 2 次及以上：略粗、颜色更实
- 多次线路画在单次之上。线路用同一色，不按车型上色。
- 往返画成两条反向弧，不要叠成一条；悬停可区分方向。
- 地图区域尽量铺满：卡片少留白，高度足够让中国底图显得更宽。底图可滚轮缩放、拖动平移；控件只保留放大 / 缩小 / 复位，不写「滚轮缩放 · 拖动平移」。

## 总览统计

布局：顶部五张数字卡片 → 地图 → **同一行三块图**，次序为 **车型、城市、按年**。窄窗再改为上下叠。

### 乘车总时长

- 展示单位用**小时**（可带分钟），不要折成「N 天」。
- 只累计**同时有开车、到达时刻**的行程，用钟点差，不估算。缺到达或出发的车次不计入总时长。
- 到达钟点**不晚于**出发，视为次日，加 24 小时。档案只存 `HH:mm`，跨两天及以上无法区分，仍按跨一天。

### 票价合计

- 单位元；只累计**填写了票价**的行程，缺省的不估、不计。
- 未全部填写时，卡片可附「已填 N 条」。

### 城市统计

- 只看行程的起点、终点；同城多站合并（优先车站表 `city`，自定义站才按站名猜）。
- 一条行程给起点城市 +1；终点是另一座城市再给终点 +1。同城往返只计 1 次。
- 条形图取次数最高的 **10** 座。主排序是次数（高→低）；次数相同则**最近一次到访**在前（日期 + 时刻；跨天到达算到次日）。
- 「到过城市」卡片是去重后的全部城市数，可以大于图上的 10 条。

### 车型

只按车次首字母分成五类：**高铁**（G）、**动车**（D）、**城际 C**（C）、**直达 Z**（Z），其余（K / T / Y / S / L / N、纯数字等）一律 **普速**。档案里旧的细分类型读入时按车次重归。

## 行程列表

- 到达时刻在跨天时标橙色 **+1**（如 `17:39`⁺¹）。编辑表单里两个时刻对得上跨天时，到达时刻旁同样出现标记。
- 列表按日期新→旧；可按年、车型筛选，可搜车次 / 车站。列出席别与票价；票价未填显示 —。

## 导入

- 「选择图片」即可，不要写「选择多张图片」。不要写「macOS 多选请按住 Command…」。
- **确认入库**、**清空列表**只在已有核对草稿后出现（选图、选文件夹、拖入或 12306 同步之后）。未导入时工具栏只留来源、选图、文件夹、12306。
- 草稿勾选后才能入库；空列表用短句引导拖入。
- 同一日期、车次、起讫站再导入时，不新增一条；只把当时空着的票价、席别、时刻等补上，已经填过的不改。没有任何新信息才跳过。

## 录入

- 手录一条与智能导入（粘贴多行文本）分开。智能导入先 **解析预览**，核对后再 **导入**。预览下方「请先勾选要导入的记录」右侧可 **全部选中**。同一行程再导入只补空字段。工具栏「导出」用于备份，不跟解释句。票价选填，单位元。
