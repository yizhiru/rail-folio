# 火车记产品规则

界面与统计口径。实现落在 `src/ui`、`src/stats`、`src/map`、`src/domain`。技术结构见 [architecture.md](architecture.md)。

## 文案

- 按钮与标题尽量短。解释性文字不常驻页面，放进顶栏右侧 **？**：悬停或聚焦时展示当前页说明。
- 主导航在左侧：浏览（总览 / 分析 / 行程）与记录（导入 / 录入）。侧栏底部有「导出」，把行程存成 CSV 表格。本机运行，顶栏不放产品名、标记和登录。
- 空状态可以有一句操作提示（如「将图片拖到此处」），不要重复「？」里的长说明。
- 统计卡片上可以保留**数据性**附注（如「最常出现：杭州」），不要放口径说明（如「同城车站已合并」）。

各页「？」要点：

| 页 | 说明什么 |
|---|---|
| 总览 | 地图手势与城市 / 车站粒度切换（默认城市）；城市按次数、同城合并、次数相同时近的在前；常坐线路按方向分开；乘车时长与跨天；总花费只计已填写票价的；最贵一程 / 最长一程 |
| 分析 | 按年切换地图与图表；月度出行按各月次数；次数、城市、时长、票价口径与总览相同 |
| 行程 | 筛选与搜索；到达时刻 `+N` 表示 N 天后到达 |
| 导入 | 选图 / 文件夹 / 拖入 / 12306；本机处理，不保存账号密码 |
| 录入 | 手录与智能导入；数据只在本机 |

票面预览窗的操作说明同样进该窗的「？」，不在图下常驻。

## 总览地图

- **聚合粒度可切换**：右上角「城市 / 车站」分段开关，**默认城市**，选择记在本机，总览与分析页共用。
  - **城市**：同城车站合并成一个点，城市归属与统计里的「到过城市」「常去城市」同一口径（`station.city`，缺失才按站名推导）。点的位置取该城市到访车站坐标按次数加权的平均；线按「起点城市 → 终点城市」聚合，次数为两城之间全部车次之和。起讫在同一城市的行程（如上海虹桥 → 上海南）没有线可画，不算缺坐标，也不提示。
  - **车站**：一站一个点，线按「起点站 → 终点站」聚合，即原有画法，不受城市模式影响。
  - 两种粒度下的线宽分档、图例、弧度、缩放微调、悬停高亮规则相同，分档按当前粒度下的次数分布重新计算。
  - 分享图跟随当前所选粒度。
- **默认与复位始终为全国视野**，不根据行程自动调整范围。
- **地名自适应显示**：优先标注当前视野内常去的城市或车站，结合窗口大小、地点密度与文字长度自动安排名称，避让相邻节点、文字和地图控件；缩放、拖动和窗口调整时重新计算，放大后逐步补充名称。悬停或选中仍可查看其余名称。分享图固定最多 8 个。
- **视觉层次**：深海军蓝底图、低对比省界、柔和青色线路；城市用柔和青色实心圆，车站用同色圆角方块，大小随往来次数温和变化。只给最多 3 个高频地点增加淡光晕（至少 2 次，且高于当前可见节点往来次数的中位数），优先显示名称。悬停或点击选中时节点变暖白、略微放大，并突出相连线路；不使用持续流光或脉冲。提示框为深蓝灰底，名称突出、日期等次要信息弱化。控件统一底板、圆角与间距，缩放为 ＋ / − / 复位。
- **线路**按「起点 → 终点」聚合，**不分车型**；杭州→徐州与徐州→杭州仍是两条弧。次数为该方向全部车次之和。
  - 按**当前图上**各方向的次数分布分成低、中、高三档，线条依次加粗、颜色更实。分档随这份行程的频率结构变化，不是固定的「1 次 / 多次」。
  - 次数相同的方向总在同一档；只有一两种次数时就少分几档。分析页按年地图用该年行程做分档。
- 多次线路画在单次之上。线路用同一色，不按车型上色。
- 往返画成两条反向弧，不要叠成一条；悬停可区分方向。
- **弧度随距离变化**：短途弧稍鼓，跨大半个中国的长线放平，往返两条仍分在两侧。
- **图例**在右下角，只列当前图上实际出现的几档，写出该档的真实次数区间（如「1–3 次」「10–12 次」），线样与地图上同一档的粗细一致。分享图不带图例。
- **悬停提示**：线显示「起点 → 终点」、次数、首次与最近一次日期；点显示出发 / 到达各几次。城市粒度下，线和点的提示还会列出实际涉及的车站（点最多列 5 个，按次数排序），与名称相同时不重复。悬停点时，与它相连的线一并点亮。点击节点可保留选中状态，再次点击该节点、点击地图空白处或复位可取消；切换粒度后清除选择，缩放时保留选择。
- **随缩放微调**：放大时圆点和线略粗，缩小时略细，幅度克制（0.8–1.7 倍），不随缩放线性放大。分享图不受影响。
- **缺坐标提示**：起点或终点所在的点没有坐标的行程画不出来，左上角用一句话提示数量，不静默丢弃。
- **空状态**：没有行程时，地图中央写一句「导入行程后，这里会出现你的足迹」。
- 地图区域尽量铺满：卡片少留白，高度足够让中国底图显得更宽。底图可滚轮缩放、拖动平移；控件只有粒度开关与放大 / 缩小 / 复位，不写「滚轮缩放 · 拖动平移」。分析页按年地图用同一套规则，只画该年行程。

## 总览统计

布局：顶部五张数字卡片 → 地图 → **年度一行三块**：并排的 **年度出行**（次数）、**年度花费**与**年度新增足迹** → **同一行两块**：**常去城市、常坐线路** → 最下两张极值卡片（最贵一程、最长一程）。窄窗再改为上下叠。

### 年度出行与年度花费

- **分成两张卡片**，不放进同一张双轴图：次数与金额单位不同，两条纵轴之间没有可比关系；折线又会把离散的年份连成「趋势」；而且花费只含已填票价，完整度与次数不同，需要自己的说明。
- 两张图都是柱状图，横轴是同一排年份、绘图区边距相同，上下对照。次数用蓝色，花费用橙色。
- **年度花费**标题右侧只写累计金额，如「累计 2542.5 元」，不写已填几条。累计等于顶部「总花费」，各年花费之和也等于它。
- 一年里一条票价都没填，这一年不画柱（不画成 0）；悬停写「未填票价」。其余年份悬停写「花费 X 元」。
- 所有行程都没填票价时，花费卡片不出图，只写「还没有填写票价的行程」。
- **年份窗口**：年度出行、年度花费、年度新增足迹三张图共用一个窗口，最多显示 **16 年**，默认是最近 16 年。年份超过 16 时，「年度出行」标题右侧出现「‹ 2009–2024 ›」，点 ‹ 往更早翻、点 › 回到更近；到头的那一侧按钮置灰。不超过 16 年时不出现翻页。
- **不设年数上限**：翻页只是分段显示，所有年份都能看到；窗口外的年份不丢，「累计」始终是全部年份的合计。
- **补齐空年份**：窗口内中间没有行程的年份补成 0 次（悬停写「没有出行」），横轴始终是连续的年份，不会让相隔几年的两年挨在一起。
- **年份标签**：超过 10 年时缩写成「’09」，保证每一年都有标签。

### 年度新增足迹

- 并列双柱展示各年的**新增城市**（蓝色）和**新增车站**（橙色），悬停显示两项数量；无新增的年份为 0。
- 只看起点与终点；城市沿用 `cityOfStation` 的同城归并口径，车站按 id 去重，不统计途经地点。
- 首次到访按**整份档案**中最早出现的日期判断，与录入顺序无关。第一年出现的所有城市、车站均算新增；补录更早的行程后重新归属年份。
- 起点按出发日期，终点按到达日期（明确跨日天数优先，否则沿用时刻推断）。跨年首次到达计入下一年，即使该年没有出发行程，也保留这一年份。
- 各年新增城市、车站合计分别等于总览的到过城市、到过车站总数；与年度出行、年度花费共用年份窗口，空白年份补 0。

### 乘车时长

- 展示为 **`11 h 11 min`**：数字与单位分色、分字体。不足 1 小时只写 min；整小时不写 0 min；不要折成「N 天」。
- 只累计**同时有开车、到达时刻**的行程，用钟点差，不估算。缺到达或出发的车次不计入乘车时长。
- 明确填写跨日天数时，按该天数计算，支持超过 24 / 48 小时的行程。未填写的旧记录仍按到达钟点**不晚于**出发推断次日，加 24 小时。手录、编辑和导入核对可填写天数；12306 返回完整到达日期时自动计算。CSV 保留原有列，明确的天数写在到达时间中，例如 `12:00 (+2天)`，导回时还原。

### 总花费

- 单位元；只累计**填写了票价**的行程，缺省的不估、不计。
- 未全部填写时，卡片可附「已填 N 条」。

### 最贵一程 / 最长一程

- **最贵一程**：只看已填写票价的行程，取金额最高的一条；金额相同则日期（及开车时刻）更近的在前。主数字是票价；下面一行：起讫站（14px，正文色）+「2024年8月18日 · G80」（13px，灰色；日期用中文年月日，不补零，不用 `2024-08-18`），放不下时日期车次整段折到下一行。没有已填票价时显示 —。
- **最长一程**：只看同时有开车、到达时刻的行程，取耗时最长的一条；耗时相同则更近的在前。主数字是耗时（格式同乘车时长），下面一行同上：起讫站、日期 · 车次。没有可计时长时显示 —。

### 常去城市

- 只看行程的起点、终点；同城多站合并（优先车站表 `city`，自定义站才按站名猜）。
- 一条行程给起点城市 +1；终点是另一座城市再给终点 +1。同城往返只计 1 次。
- 条形图取次数最高的 **10** 座。主排序是次数（高→低）；次数相同则**最近一次到访**在前（日期 + 时刻；跨天到达按跨日天数顺延）。
- 「到过城市」卡片是去重后的全部城市数，可以大于图上的 10 条。

### 常坐线路

按车站（不是城市）和方向聚合，去和回分开；取次数最高的 **6** 条，和同一行图卡高度对齐。

### 车型字段

总览、分析与地图提示不再展示车型统计。现有车型字段仅用于档案兼容与行程列表筛选，按车次首字母分成五类：**高铁**（G）、**动车**（D）、**城际 C**（C）、**直达 Z**（Z），其余（K / T / Y / S / L / N、纯数字等）一律 **普速**。档案里旧的细分类型读入时按车次重归。

## 分析

总览给全貌，分析按切片看明细。布局：选年份 → 该年卡片与地图 → **同一行两块**：**月度出行、常去城市**。窄窗再改为上下叠。

- **次数**：该切片里的行程条数。
- **城市**：只计起点和终点，同城合并，口径与「到过城市」相同。
- **时长 / 花费**：只累计已填写的；没有则显示 —。未填全时卡片可附「已填 N 条」。
- **按年**：下拉切换有出发行程或跨年首次到达的年份。该年用六张卡片展示次数、城市、时长、花费、新增城市、新增车站；地图与总览相同（只含该年出发行程）；图为月度出行、常去城市。
- **新增城市 / 新增车站**：与总览年度新增足迹相同，先按整份档案确定首次到访，再取所选年份；此前已到访的地点不重复算新增。没有新增时显示 0。
- **月度出行**：柱状图，横轴为该年 1–12 月，纵轴为行程条数（与次数卡片同一口径）。没有行程的月份计 0。

## 行程列表

- 到达时刻在跨天时标橙色 **+N**，表示 N 天后到达。编辑表单可填写跨日天数，到达时刻旁同步显示标记；留空时按时刻推断。
- 列表按日期新→旧；同一天按出发时刻晚→早，没有出发时刻的排在当天有时刻的行程之后。可按年、车型筛选，可搜车次 / 车站。列出席别与票价；票价未填显示 —。

## 导入

- 「选择图片」即可，不要写「选择多张图片」。不要写「macOS 多选请按住 Command…」。
- **确认入库**、**清空列表**只在已有核对草稿后出现（选图、选文件夹、拖入或 12306 同步之后）。未导入时，图片导入与 **12306 同步**分两块；后者单独一区。
- **12306 同步**必须先填**乘车人姓名**（留空时按钮不可点）：同一订单可含多位乘车人，只收这位的车票。姓名记在本机。订单里找不到该姓名时，提示订单中出现的乘车人。
- 草稿勾选后才能入库；空列表用短句引导拖入。
- 同一日期、车次、起讫站再导入时，不新增一条；只把当时空着的票价、席别、时刻等补上，已经填过的不改。没有任何新信息才跳过。

## 录入

- 手录一条与智能导入（粘贴多行文本）分开。智能导入先 **解析预览**，核对后再 **导入**。预览下方「请先勾选要导入的记录」右侧可 **全部选中**。同一行程再导入只补空字段。票价选填，单位元。
- **导出**在左侧栏底部，不跟解释句。点下去选择保存位置，把当前行程写成 CSV（UTF-8 带 BOM，Excel 直接打开不乱码）。列为：日期、车次、出发站、到达站、出发时间、到达时间、席别、票价、里程、备注；车站写站名，不带 id、指纹、车型、来源和导出时间这类内部字段，没有值的格留空。行按行程页的顺序排：日期新的在前，同一天晚出发的在前。文件可读回：站名按内置站表匹配，匹配不上的新建自定义站（城市按站名推导、无坐标），车型与指纹由车次、日期、起讫站重新算。
